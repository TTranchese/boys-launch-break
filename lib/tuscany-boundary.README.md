# Tuscany map boundary

Source: [geojson-italy regional boundaries](https://github.com/guglielmo/geojson-italy/blob/main/geojson/limits_IT_regions.geojson), Toscana (ISTAT code 09).

© ISTAT, distributed by geojson-italy under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Modified for this app: exterior rings extracted, simplified with Douglas–Peucker tolerance 0.0005 degrees, rounded to five decimals, and stored in Leaflet latitude/longitude order. Islands retained. For visual emphasis, not a survey boundary. Attribution also appears on the live map.
